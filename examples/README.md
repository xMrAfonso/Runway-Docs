## Before You Paste

- Quote formatted YAML values because hex colors, colons, and URLs can confuse YAML.
- Match your prefix mode. Examples use `$` unless noted.
- Enable the right listener. A perfect message will still stay plain if its listener is off.
- Test with `/runway parse` to catch MiniMessage syntax problems early.
